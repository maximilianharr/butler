# Files

Shows the files of the content folder on the left pane. Can be shown/unshown via clicking on the files icon in the leftmost pane and also via the shortkey in settings folder.
Each folders and subfolders can be expanded and unexpanded by clicking on the folger name. An expanded folder has a '>' sign before the folder name showing downwards a unexpanded folder has a '>' sign. Going deeper in the subfolders the indent is increased by two spaces. The file names with their extension are shown. If they have a title denoted by markdown '#' sign then this title is used of the first title with one hash.
New files (untracked by git) are green font color. Modified files (changed to last git commit) are orange font color.
