# Content Folder

This folder contains sample content for your zettelkasten and the respective plugins.

The 'zettelkasten' folder contains the four folders from the [PARA method of Tiago Forte](https://fortelabs.com/blog/para/): 
- **project** short-term efforts in your work or life that you're working on now
- **area** long-term responsibilities you want to manage over time
- **resource** topics or interests that may be useful in the future
- **archive** inactive items from the other three categories

The 'plugins' folder contains a subfolder for each plugin. Each plugin subfolder contains the respective markdown files of this plugin.

The 'resources' folder contains all non-markdown files such as images, zip files, pdfs, etc.
